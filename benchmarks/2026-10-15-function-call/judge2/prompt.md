You are an expert judge of technical explainers. Compare two web pages, A and B. Both were made for the same request:

"Create an explainer that visualizes how a function call works in all the languages."

Files in the current directory:
- A/page.html and B/page.html: the full source of each page. Each is one self-contained HTML file.
- A/shot-*.png and B/shot-*.png: screenshots of each page at desktop width, in different states (different steps or scenes). shot-phone.png is the page at 390 px phone width.

Steps:
1. Look at every screenshot of both pages. They show what a reader sees.
2. Read both HTML files. Read the scripts too: they show what each page does when the reader clicks, presses keys, or waits.
3. Check the technical claims, the code samples and the numbers. Report every factual error you find.
4. Score each page from 1 to 10 on each criterion below. Use the whole scale. A 10 means nothing could be better.

Criteria:
- accuracy: the technical claims, code and numbers are correct.
- core_idea_clarity: after one viewing, a newcomer could explain how a function call works (arguments, parameters, the stack frame, return, return to the caller).
- visual_explanation: the visuals show the real mechanism, not only text next to pictures.
- interactivity: the reader can explore, step and change things, and the motion helps understanding.
- language_coverage: how well the page answers "in all the languages".
- depth: useful insight beyond the basics.
- visual_design: polish, layout, typography, colour use and consistency.
- mobile_and_accessibility: works at phone width, keyboard use, readable text, reduced motion.

Then pick an overall winner: "A", "B" or "tie". Judge which page better serves a reader who asked this request. Do not prefer a page because it is longer, and do not prefer A or B because of its position. Give your reasons in a few short sentences, and name the single biggest strength and the single biggest weakness of each page.

In "screenshots_viewed", list every screenshot file you really opened.
