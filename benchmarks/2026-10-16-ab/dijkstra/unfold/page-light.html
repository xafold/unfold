Cost of the queue

The figure keeps the queue sorted, so it reads like the array version. Real code uses a binary heap.

queueextract-minlower a dwhole run
array scanO(V)O(1)O(V²)

Negative weights break it

A final d is safe only if no edge can make a longer path cheaper.

Variants you will meet

variantwhat changes
lazy deletionpush a new queue entry on each lower, skip stale entries on pop (Python heapq)
early stopstop when the target node is taken, its d is already final
directed graphrelax only the edges that leave u
A*order the queue by d(v) + h(v), an estimate of the rest
