Why it is correct
When a node u is popped with the smallest tentative distance, every other route to u must leave the settled set through some frontier node that is already at least as far. Since weights are non-negative, that detour can only add cost. So dist[u] is final.

  
Relaxation
For edge (u, v) with weight w: if dist[u] + w < dist[v], we found a shorter way to v through u. Update dist[v], remember prev[v] = u, and push v into the queue.

  
Cost
With a binary heap: each edge pushes at most one entry, so O((V + E) log V). Negative weights break the proof above; use Bellman-Ford for those.
