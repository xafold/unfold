Why the factor is 1 − 2η

Put the slope into the update rule: w − η·2(w − 3) − 3 = (1 − 2η)(w − 3). So the distance to the minimum is multiplied by the same number at every step. The size of that number decides what happens.

Learning rate ηFactor 1 − 2ηWhat happens
0 < η < 0.5between 0 and 1w moves toward 3 from one side. A small η means many steps.
η = 0.50w lands on 3 in one step. This only works because the loss is an exact parabola.
0.5 < η < 1between −1 and 0w jumps over 3 every step, but the jumps shrink. It still converges.
η = 1−1w bounces between 0 and 6 forever.
η > 1below −1w jumps over 3 and lands further away each time. The loss grows.

The general rule

The limit of 1 comes from the curvature. Here the second derivative is L″ = 2, and a step is stable only when η < 2 / L″. A steeper valley needs a smaller learning rate. In a real model, the curvature differs per direction. The steepest direction sets the largest safe rate, and the flattest direction then moves slowly.

What this figure leaves out

  • Many parameters. A real model has millions of parameters. L′ becomes the gradient vector ∇L, but each parameter follows the same rule.
  • Noisy gradients. Stochastic gradient descent estimates the gradient from a small batch of data, so each step is a little wrong.
  • Curves that are not parabolas. A real loss can have flat regions, saddle points and several minima. The rule only sees the local slope.
  • Better update rules. Learning-rate schedules, momentum and Adam change the step size during training.

Terms

  • Parameter (w): the number the model learns.
  • Loss (L): one number that says how wrong the model is. Lower is better.
  • Slope or gradient (L′): how fast the loss changes when w changes. Its sign points uphill.
  • Learning rate (η): the number that scales each step.
  • Converge / diverge: the steps settle at the minimum, or they move further away.
