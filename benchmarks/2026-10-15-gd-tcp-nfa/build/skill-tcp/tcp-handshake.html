The figure's numbers come from a small model of two TCP endpoints (model.mjs). To check it, capture.sh runs a real connection on Linux 7.1 over loopback, in a private network namespace, and records it with tcpdump -S. What the figure leaves out

  • Header fields: window size, checksum, urgent pointer and options. The real SYNs also carry options: MSS, SACK permitted, window scale and timestamps.
  • Loss: no segment is lost or sent again. A lost SYN or FIN is sent again after a timeout, with the same sequence number.
  • Three-segment close: if the server closes at once, it can put its ACK and its FIN in one segment (FIN,ACK). capture.sh waits 0.3 s before the server closes, so the capture has the 4-segment close drawn here.
  • RST: a reset ends a connection at once, without FIN and without TIME-WAIT.
  • Simultaneous open and close: both sides send SYN (or FIN) at the same time. The state machine has extra paths for this.
  • Random ISN: RFC 6528 makes the ISN from a clock plus a keyed hash of the addresses and ports, so an attacker cannot guess it. Sequence numbers are 32-bit and wrap around after 232 − 1.
  • TIME-WAIT length: RFC 793 suggested an MSL of 2 minutes. Linux uses a fixed TIME-WAIT of 60 s.

Terms

  • Segment: one TCP packet: a header and optional data.
  • ISN (initial sequence number): the first sequence number a side uses. Each side picks its own.
  • seq: the number of the first byte in this segment. A SYN or a FIN carries no data, but uses one sequence number.
  • ack: the next sequence number the sender expects from the other side. It is valid only when the ACK flag is set.
  • SND.NXT and RCV.NXT: the next number a side will send, and the next number it expects to receive. Every ack is the sender's RCV.NXT.
  • Relative numbers: Wireshark and tcpdump subtract the ISN by default, so the SYN shows seq 0 and its answer shows ack 1. tcpdump -S shows the real numbers.
  • MSL (maximum segment lifetime): the longest time a segment can stay in the network. TIME-WAIT lasts 2 MSL, so old copies die before the same ports are used again.
