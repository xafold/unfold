How a hash table stores keys

A hash table turns each key into a number, and uses that number to pick a bucket in an array. Two keys can pick the same bucket. When the table gets too full, it doubles the array and moves the keys. Add keys below and watch each step.

Hashing

The hash function reads the key one character at a time: h = h × 31 + code. The same key always gives the same number. The bucket is h mod capacity. The capacity is a power of two, so this is the last few bits of h.

Collisions

Each bucket holds a short chain (a linked list). A new key that lands in a used bucket goes to the end of the chain. A lookup checks the chain one key at a time, so long chains make lookups slow.

Growing

When keys / buckets goes above 0.75, the table doubles. Each key is placed again with one more bit of its hash. If that bit is 0, the key stays at index i. If it is 1, it moves to i + old capacity.
