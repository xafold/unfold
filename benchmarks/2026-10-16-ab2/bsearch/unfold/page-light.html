The loop in code

function binarySearch(a, t) { let low = 0, high = a.length - 1; while (low <= high) { const mid = Math.floor((low + high) / 2); if (a[mid] === t) return mid; if (a[mid] < t) low = mid + 1; else high = mid - 1; } return -1; }

How the count grows

The binary column is ⌊log₂ n⌋ + 1. A miss leaves at most ⌊n/2⌋ cells, so each compare at least halves the range.

What the figure leaves out

casewhat to know
Unsorted arrayThe search gives wrong answers. Sort first, or use a hash table.
Repeated valuesThis loop returns any matching index, not the first.
Finding the first matchKeep searching left after a hit (lower bound).
Integer overflowIn C or Java, low + high can overflow. Use low + (high − low) / 2.
Half-open rangeMany libraries use [low, high). The loop test becomes low < high.
