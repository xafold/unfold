Mistakes that break it

mistakewhat happens
lo = mid in place of mid + 1the range can stop shrinking, and the loop never ends
while lo < hi with hi = mid - 1the last candidate is never probed
(lo + hi) / 2 in 32-bit intsoverflow above 2³⁰ cells, use lo + (hi - lo) / 2
array not sorteda cut can rule out t, and the search returns −1
